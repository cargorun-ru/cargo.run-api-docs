# **CARGO.RUN Загрузки** — Документация по API

Документация описывает интеграцию внешних учетных систем с продуктом **CARGO.RUN Загрузки**.

Основной сценарий интеграции: грузоотправитель или экспедитор подключает свою систему, например 1С или ERP, чтобы создавать заказы в CARGO.RUN, получать отклики перевозчиков и забирать результаты выполнения перевозок обратно в свою систему.

Дополнительно описан сценарий перевозчика: получение доступных заказов, отправка отклика, работа со справочниками ТС, прицепов и водителей.
