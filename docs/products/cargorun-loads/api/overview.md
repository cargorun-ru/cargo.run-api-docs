# Обзор API

API **CARGO.RUN Загрузки** работает по HTTP/HTTPS и использует JSON для запросов и ответов.

---

## 1. Базовый URL

Фактический базовый URL предоставляется при подключении интеграции.

В примерах используется:

```text
<baseUrl>
```

Итоговый URL метода:

```text
<baseUrl>/api/Orders/GetIntegrationList
```

---

## 2. Авторизация

В большинстве методов требуется заголовок:

```http
Authorization: Bearer <access_token>
```

Подробнее: [Авторизация](./auth.md)

---

## 3. Формат ошибок

Типовые коды:

| Код | Значение |
|---:|---|
| `200` | Успешное выполнение |
| `400` | Ошибка валидации или бизнес-логики |
| `401` | Нет авторизации или токен недействителен |
| `500` | Внутренняя ошибка сервера |

При ошибке `400` тело ответа может содержать подробности валидации.

---

## 4. Списки

Методы списков обычно поддерживают:

- `$filter`;
- `$orderby`;
- `$top`;
- `$skip`.

Ответ:

```json
{
  "data": [],
  "totalCount": 0
}
```
