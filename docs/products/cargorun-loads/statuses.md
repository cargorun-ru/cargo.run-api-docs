# Статусы

В этом разделе приведены основные enum-значения, которые используются в API CARGO.RUN Загрузки.

---

## 1. Статусы заказа (`OrderStatus`)

| Код | Значение | Описание |
|---:|---|---|
| `5` | `Draft` | Черновик |
| `10` | `New` | Новый заказ |
| `20` | `InSearch` | Поиск перевозчика |
| `25` | `HasResponses` | Есть отклики перевозчиков |
| `30` | `InWork` | Заказ в работе |
| `35` | `InProgress` | Исполняется |
| `40` | `Completed` | Завершен |
| `50` | `Canceled` | Отменен |

---

## 2. Тип цены заказа (`OrderPriceType`)

| Код | Значение | Описание |
|---:|---|---|
| `10` | `Static` | Фиксированная стоимость |
| `20` | `Auction` | Аукцион |
| `30` | `Offer` | Предложение цены |

Для `Auction` и `Offer` ставка перевозчика обязательна. Для фиксированной стоимости ставка может не требоваться.

---

## 3. Тип доступа к заказу (`OrderAccessType`)

| Код | Значение | Описание |
|---:|---|---|
| `10` | `Public` | Публичный заказ |
| `20` | `RelationsOrganizationsOnly` | Только связанные организации |
| `30` | `SelectedRelationsOrganizationsOnly` | Только выбранные связанные организации |

При `SelectedRelationsOrganizationsOnly` список организаций задается в `visibleForOrganizationsIds`.

---

## 4. Статусы отклика (`MatchingStatus`)

| Код | Значение | Описание |
|---:|---|---|
| `10` | `AcceptedInTruckOwner` | Принят перевозчиком |
| `20` | `DeclinedInTruckOwner` | Отклонен перевозчиком |
| `30` | `AcceptedInOrderOwner` | Принят владельцем заказа |
| `40` | `DeclinedInOrderOwner` | Отклонен владельцем заказа |
| `50` | `Awaiting` | Ожидает решения |

Для основного сценария грузоотправителя/экспедитора ключевой переход — принятие отклика владельцем заказа через `POST /api/OrderTruckMatchings/Accept`.

---

## 5. Статусы заявки перевозчика (`BidStatus`)

| Код | Значение | Описание |
|---:|---|---|
| `20` | `Draft` | Черновик |
| `25` | `Planned` | Запланирована |
| `30` | `Started` | Запущена |
| `40` | `AtLoading` | На погрузке |
| `41` | `Loaded` | Загружена |
| `42` | `AtUnloading` | На выгрузке |
| `43` | `Unloaded` | Разгружена |
| `50` | `Canceled` | Отменена |
| `60` | `Done` | Выполнена |

---

## 6. Тип точки маршрута (`PointType`)

| Код | Значение | Описание |
|---:|---|---|
| `0` | `Default` | Не задано |
| `10` | `Load` | Погрузка |
| `20` | `Unload` | Выгрузка |
| `30` | `Transit` | Транзит |
