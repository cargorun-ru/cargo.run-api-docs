# Возможные значения полей

Все enum в запросах, синхронных ответах, результатах очереди и webhook передаются в JSON строковыми именами, указанными в колонке `JSON`. Числовые коды приведены только как справочная информация и не являются wire-форматом API.

## `BidStatus`

| JSON | Код в реализации | Значение |
|---|---:|---|
| `New` | 0 | Черновик |
| `Planned` | 5 | Запланирована, но ещё не запущена |
| `Started` | 10 | Запущена в работу |
| `Canceled` | 20 | Отменена |
| `Done` | 30 | Выполнена |

### Жизненный цикл заявки

Для заявки, успешно созданной через `Bids/Apply`, основной наблюдаемый путь выглядит так:

```text
Started → Done
   └──→ Canceled
```

`New` означает черновик, `Planned` — запланированную заявку до запуска, `Started` — заявку в работе, `Done` — завершённую, `Canceled` — отменённую. Метод `Bids/Apply` после успешного создания запускает заявку в работу, поэтому партнёр обычно получает `Started`. CARGO.RUN может вернуть заявку в работу, поэтому обработчик партнёра не должен считать статусы монотонными. Диаграмма описывает партнёрский сценарий, а не полный перечень разрешённых переходов пользовательского интерфейса CARGO.RUN.

Текущий статус всегда определяется по полю `status` карточки или краткой модели заявки. Изменение статуса также может поступить через `entity.changed`.

## Значения ошибок в разных enum

Одинаковое имя `Error` относится к разным уровням обработки:

| Поле | Enum | Что означает `Error` |
|---|---|---|
| `QueuedApiTaskGetResultsModel.status` | `QueuedApiTaskStatus` | Системная ошибка задачи целиком; результат мог не быть сформирован |
| `objects[].status` | `QueuedApiTaskObjectResultStatus` | Ошибка обработки конкретного объекта; остальные объекты задачи могут быть успешны |
| `callbackStatus` | `QueuedApiTaskCallbackStatus` | Все предусмотренные попытки доставки webhook для задачи завершились ошибкой |
| `QueuedApiTaskObjectStatusJson.type` | `QueuedApiTaskSyncStatus` | Диагностический уровень статуса синхронизации объекта |

Проверяйте эти поля независимо. Например, задача может иметь `status=Completed`, один объект — `status=Error`, а webhook — `callbackStatus=Delivered`.

## `SourceType`

Поле является выходным признаком источника заявки. Партнёр не передаёт `sourceType` при `Bids/Apply` и в документированных командах очереди. Для заявки, созданной партнёрской интеграцией, CARGO.RUN устанавливает `ExternalIntegration`; у связанной заявки, созданной перевозчиком, может вернуться другой источник.

|---|---:|
| `Web` | 0 |
| `Enterprise` | 1 |
| `Forwarding` | 2 |
| `Exploitation` | 3 |
| `Kontur` | 4 |
| `ExternalIntegration` | 5 |
