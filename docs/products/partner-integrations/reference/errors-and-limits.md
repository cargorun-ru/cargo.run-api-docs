# Ошибки и ограничения

## HTTP-ошибки

| Код | Причина | Повтор |
|---:|---|---|
| `400` | Неверные поля или бизнес-правило | Только после исправления |
| `401` | Недействительный или истёкший токен | Один раз обновить токен |
| `403` | Нет доступа к операции или организации | Только после изменения прав |
| `404` | Ресурс не найден в методах, где этот статус явно предусмотрен | Не повторять без проверки параметров |
| `429` | Слишком частые запросы | После `Retry-After` или паузы |
| `5xx` | Временная серверная ошибка | Ограниченно, с exponential backoff и jitter |

Синхронные бизнес-ошибки могут возвращаться как `text/plain`.

Иллюстративный пример ошибки валидации; конкретный текст зависит от нарушенного правила:

```http
HTTP/1.1 400 Bad Request
Content-Type: text/plain; charset=utf-8

Для заявки необходимо указать не менее двух точек маршрута.
```

Синхронные методы чтения заявки `Bids/Get`, `GetActualRoute`, `GetPlannedRoute`,
`GetEvents` и `GetDriverMessages` при отсутствии, удалении или недоступности заявки
обычно возвращают `200 OK` с пустым телом. Проверяйте наличие тела до
десериализации. По ответу нельзя различить отсутствие заявки и отсутствие доступа.

## Текстовые ошибки `Bids/Apply`

Бизнес-ошибка синхронного `Bids/Apply` обычно возвращается с HTTP `400` как текст.
В асинхронном `Write` тот же текст находится в `objects[].message`.

Текст предназначен для диагностики и не является стабильным машинным кодом: после
интеграционной проверки выполняются общие проверки заявки, организации, машины и
водителя, поэтому возможны дополнительные сообщения. Клиенту следует принимать
решение по HTTP-статусу или статусу объекта очереди, а полный текст сохранять в
логах.

Основные сообщения:

| Область | Возможное сообщение |
|---|---|
| Данные заявки | `Не указаны данные заявки.` |
| Организация | `Не указан ИНН организации перевозчика.` |
| Организация | `ИНН организации … некорректен: ожидается 10 или 12 цифр.` |
| Организация | `Организация с ИНН … не найдена.` |
| Доступ | `У площадки нет доступа к указанной организации.` |
| Возможности клиента | `Для этой площадки не разрешено упрощенное создание заявок.` |
| Маршрут | `Не указаны точки заявки.` |
| Маршрут | `Заявка должна содержать хотя бы одну точку загрузки и выгрузки.` |
| Тип точки | `Тип точки N должен быть точкой погрузки или выгрузки.` |
| Дата точки | `Не указана дата загрузки/выгрузки для точки N.` |
| Адрес точки | `Не указан адрес точки N.` |
| Геокодирование | `Не удалось определить координаты точки N по адресу «…».` |
| Координаты | `Некорректные координаты точки N: ожидается [долгота, широта].` |
| Груз | `Заявка должна содержать хотя бы один товар.` |
| НДС | `Не указана ставка НДС: она обязательна, если указана стоимость перевозки.` |
| Автомобиль | `Не указан государственный номер автомобиля.` |
| Автомобиль | `Некорректный государственный номер автомобиля «…».` |
| Автомобиль | `Не указана марка автомобиля.` |
| Прицеп | `Не указан государственный номер прицепа.` |
| Водитель | `Не указан номер телефона водителя.` |
| Водитель | `ФИО водителя не должны превышать 256 символов.` |
| Водитель | `Некорректные ФИО водителя «…»: укажите фамилию, имя и отчество (при наличии) через пробел.` |
| Контрагент | `Не указано наименование контрагента.` |
| Контрагент | `Не указан ИНН контрагента.` |
| Температура | `Не указаны минимальная и максимальная температура.` |
| Температура | `Минимальная температура должна быть меньше максимальной.` |
| Тип ТС | `Не указаны тип ТС, тоннаж или объем.` |
| Запуск заявки | `Уже имеется начатая заявка с данной машиной.` |
| Планирование | `Достигнут лимит запланированных заявок: N. Текущая заявка сохранена как черновик.` |

Сообщение о недопустимом типе точки сформулировано как «точка погрузки или
выгрузки», но входное значение `LoadUnloadPoint` также поддерживается. Ошибка
возникает для отсутствующего типа и значений `StartPoint`, `CustomPoint` или
`ServicePoint`.

Ошибка о начатой заявке проверяет занятость автомобиля, а в специальном режиме —
прицепа. Без модуля планирования наличие другой активной заявки может блокировать
запуск независимо от пересечения плановых дат и независимо от водителя.

## Ошибки очереди

| Уровень | Поле | Успех | Ошибка | Где читать причину |
|---|---|---|---|---|
| Постановка команды | `commands[].status` | `Success` | `Failed` | `commands[].message` |
| Задача целиком | `QueuedApiTaskGetResultsModel.status` | `Completed` | `Error` | `message` |
| Объект задачи | `objects[].status` | `Success` | `Error` или `VersionMismatch` | `objects[].message` |
| Доставка webhook | `callbackStatus` | `Delivered` | `Error` | `lastError` |
| Диагностика синхронизации | `QueuedApiTaskObjectStatusJson.type` | `Info` | `Warn` или `Error` | `QueuedApiTaskObjectStatusJson.message` |

Эти уровни независимы. `Completed` означает, что обработка задачи закончена, но не гарантирует успех каждого элемента `objects[]`. Аналогично, `callbackStatus=Delivered` подтверждает только доставку webhook и ничего не говорит об успешности объектов.

`VersionMismatch` используется механизмом `ReadConfirmation`, который партнёрским интеграционным клиентам недоступен. В документированных командах `Write`, `Read` и `ReadQuery` партнёр не должен получать этот статус. Если он всё же появился, не подтверждайте локальную версию объекта, зарегистрируйте диагностическое событие и заново прочитайте актуальные данные.

## Подтверждённые ограничения

| Ограничение | Значение |
|---|---|
| Получение токена | Не чаще двух запросов за 30 секунд |
| `Idempotency-Key` | Не более 100 символов, действует 24 часа |
| Точки заявки | Минимум 2 |
| Состав маршрута | Хотя бы одна погрузка и одна выгрузка |
| `planEnterDate` | Обязателен для каждой точки |
| Порядок точек | Строгий хронологический после приведения к UTC |
| Адрес точки | Обязательная непустая строка, даже если координаты переданы |
| Координаты точки | Необязательны; если переданы — `[долгота, широта]`, кроме `[0, 0]`; если отсутствуют — определяются по адресу |
| ИНН | Обязателен; 10 цифр для организации или 12 для ИП |
| Автомобиль, водитель и груз | Обязательны |
| Прицеп | Необязателен; если передан, обязателен номер |
| Асинхронные типы | Только `Bid` |
| Асинхронные действия | `Write`, `Read`, `ReadQuery` |
| Фактический маршрут | Только синхронный метод |
| Автоматический пакет подписки | До 100 объектов в одной задаче по текущей конфигурации |
| Список без `$filter` | Последние 30 дней для `GetList` и `ReadQuery`; любой непустой `$filter` отменяет окно по умолчанию |
| `$top` для `GetList` и `ReadQuery` | Не более 1000 записей за запрос |
| Ссылки на файлы | Временные; файл нужно скачать сразу или повторно запросить данные для новой ссылки |

## Webhook

- порядок не гарантируется;
- возможны повторы;
- несколько изменений одной заявки могут объединяться;
- повторяются сеть, `408`, `429`, `5xx`;
- остальные `4xx` не повторяются;
- не более пяти попыток с интервалами 10, 20, 40 и 80 секунд перед повторными отправками;
- после пяти последовательных неудачных доставок подписка приостанавливается;
- во время приостановки проверочная доставка выполняется каждые 5 минут;
- успешная доставка или `Tasks/Ping` возобновляет подписку;
- отдельного публичного статуса приостановки нет, а накопившиеся изменения могут быть отброшены;
- необходим периодический контрольный `ReadQuery`.

## Неподдерживаемые операции

- `Delete` через партнёрскую очередь;
- `ReadConfirmation`;
- асинхронная работа с `Car`, `Trailer`, `Driver`, `Counterparty`, `DistributionBid`;
- фактический маршрут внутри `IntegrationBidDetailsModel`;
- частичное обновление заявки.

## Валидация новых полей заявки

| Поле | Правило | Ошибка |
|---|---|---|
| `counterparty.name` | Обязательно при переданном `counterparty` | `Не указано наименование контрагента.` |
| `counterparty.name` | Не более 256 символов | `Наименование контрагента не должно превышать 256 символов.` |
| `counterparty.inn` | Обязателен при переданном `counterparty` | `Не указан ИНН контрагента.` |
| `counterparty.inn` | Ровно 10 или 12 цифр | `ИНН контрагента … некорректен: ожидается 10 или 12 цифр.` |
| `bidPoints[].type` | Обязателен; только `LoadPoint`, `UnloadPoint` или `LoadUnloadPoint` | Ошибка о незаполненном или недопустимом типе точки |
| `vehicleType` | Хотя бы одно из `name`, `tonnage`, `volume` | `Не указаны тип ТС, тоннаж или объем.` |
| `vehicleType.name` | Не более 128 символов | `Тип ТС не должен превышать 128 символов.` |
| `vehicleType.tonnage` | Если передан — больше 0 | `Грузоподъемность должна быть больше 0.` |
| `vehicleType.volume` | Если передан — больше 0 | `Объем должен быть больше 0.` |
| `temperatureRegime` | Обязательны `minimum` и `maximum` | `Не указаны минимальная и максимальная температура.` |
| `temperatureRegime.*` | Каждая граница от −30 до 30 °C включительно | `Температура должна быть в диапазоне от -30 до 30 °C.` |
| `temperatureRegime` | `minimum < maximum` | `Минимальная температура должна быть меньше максимальной.` |
| `bidPoints[].geozone.address` | Обязательная непустая строка | `Не указан адрес точки N.` |
| `driver.fullName` | Если передано — не более 256 символов и должно распознаваться как две или три части ФИО | Ошибка о слишком длинном или некорректном ФИО |
| Геокодирование | По адресу должна определиться точка | `Не удалось определить координаты точки N по адресу «…».` |
