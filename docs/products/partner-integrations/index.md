# Интеграция с партнёрскими сервисами

Раздел описывает интеграцию CARGO.RUN с партнёрскими сервисами, которым необходимо создавать заявки перевозчиков и получать сведения о ходе их исполнения.

Документация охватывает:

- подключение и machine-to-machine авторизацию;
- проверку организаций и управление доступом;
- создание и обновление заявок;
- получение заявок, связанных с партнёрским сервисом;
- получение статусов, ETA, событий, маршрутов, сообщений и файлов;
- синхронные и асинхронные способы взаимодействия;
- подписки и webhook;
- восстановление синхронизации после ошибок.

## Основные сценарии

### Партнёрский сервис создаёт заявку

Партнёрский сервис получает доступ к организации перевозчика, создаёт или обновляет заявку и затем отслеживает её исполнение.

### Перевозчик связывает заявку с партнёрским сервисом

Перевозчик создаёт заявку в CARGO.RUN и указывает партнёрский сервис и идентификатор заказа. Партнёр получает эту заявку и сведения о её исполнении без права создавать другие заявки организации.

## Способы взаимодействия

| Способ | Назначение |
|---|---|
| Синхронное API | Простые вызовы с результатом в ответе на тот же запрос |
| Асинхронная очередь | Пакетные и фоновые операции с получением результата по идентификатору задачи или через webhook |
| Подписка | Оперативное уведомление партнёра об изменении связанной заявки |

Рекомендуемая интеграция сочетает webhook для оперативных изменений с периодической контрольной синхронизацией.
