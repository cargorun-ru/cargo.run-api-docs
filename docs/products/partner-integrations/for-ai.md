# Для LLM и ИИ-агентов

Документация доступна в двух машиночитаемых представлениях.

## Индекс документации

[Открыть `llms.txt`](../../llms.txt)

Краткий индекс содержит ссылки на разделы документации и поясняет назначение каждого раздела. Используйте его, если ИИ-агент может самостоятельно открывать ссылки и загружать необходимые материалы.

## Полная документация

[Открыть `llms-full.txt`](../../llms-full.txt)

Файл содержит весь раздел интеграции с партнёрскими сервисами в одном документе. Используйте его для систем без доступа к сайту, подготовки базы знаний или передачи полного контекста модели.

## Рекомендации

- Начинайте с `llms.txt`, чтобы не загружать лишний контекст.
- Используйте `llms-full.txt`, если агенту требуется анализ всей интеграции или проверка связей между сценариями, методами и моделями.
- Считайте опубликованную документацию источником требований к интеграции. Секреты, токены и реальные персональные данные в контекст модели не передавайте.
