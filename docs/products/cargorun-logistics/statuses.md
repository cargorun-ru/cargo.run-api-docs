# Статусы сущностей

В этом разделе собраны статусные модели ключевых сущностей **CARGO.RUN Логистика**.

---

# 1. Статусы заявок (BidStatus)

Статус отражает текущее состояние заявки.
Заявка проходит несколько этапов — от создания до завершения или отмены.

| Статус | Код | Описание |
|---|---:|---|
| `New` | `0` | Заявка создана, находится в статусе черновика. |
| `Planned` | `5` | Запланирована к выполнению. |
| `Started` | `10` | Начата, запущена в работу. |
| `Canceled` | `20` | Заявка отменена. |
| `Done` | `30` | Заявка выполнена. |

### Примечания
- Статус `New` означает, что заявка еще не запущена логистом.
- Статус `Planned` означает, что заявку попытались запустить, но транспортное средство
  занято другой заявкой и у организации включено планирование. Этот статус назначает
  система; передавать `Planned` в `SetStatus` вручную нельзя.
- При запросе `Started` итоговый статус может оказаться `Planned`. Проверяйте ответ
  команды и повторно читайте заявку.
- Переходы между статусами контролируются бизнес-логикой системы.

# 2. Статусы оплаты заявки

Статусы отражают состояние расчётов по заявке со стороны заказчика.

| Статус | Описание |
|--------|----------|
| `NotPaid` | Оплата по заявке не поступила. |
| `PartiallyPaid` | Оплачена частично. |
| `Paid` | Полностью оплачена. |
| `Expired` | Истёк срок оплаты. |

---

# 3. Статусы контрагентов

Контрагенты могут иметь различный статус, определяющий возможность работы с ними в системе.

| Статус | Описание |
|--------|----------|
| `None` | Ограничения отсутствуют. |
| `Priority` | Приоритетный контрагент. |
| `Suspended` | Работа временно приостановлена. |

---

# 4. Статусы титулов (ЭТРН)

Электронная транспортная накладная (ЭТРН) включает несколько титулов и уровней подписания.
Фактические статусы могут отличаться в зависимости от провайдера ЭТРН, поэтому здесь указаны статусы `WaybillTitleStatus`, используемые в API.

| Статус | Описание |
|--------|----------|
| `ReceivedOrCreated` | Титул получен или создан системой. |
| `Accepted` | Титул принят водителем или внешней системой. |
| `Signed` | Титул подписан. |
| `Sent` | Титул передан на отправку в ЭДО. |
| `Processed` | Титул обработан провайдером ЭТРН. |
| `Declined` | Титул отклонён. |
| `Failed` | При обработке титула возникла ошибка. |
