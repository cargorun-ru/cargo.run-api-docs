# CARGO.RUN Документация

Добро пожаловать в документацию CARGO.RUN. Это центральный сборник всех материалов для интеграции, разработки и использования продуктов CARGO.RUN.

---

## 📚 Доступные продукты

### **CARGO.RUN Логистика**
Документация по интеграции 1С с системой управления перевозками **CARGO.RUN Логистика** через REST API для транспортных компаний.

**Что внутри:**
- Вводные материалы (введение, форматы данных, статусы)
- Сценарии интеграции с внешними системами (1С, ERP, WMS)
- Полный справочник методов API
- Примеры кода и интеграции

[Документация](./products/cargorun-logistics/index.md)

---

### **CARGO.RUN Загрузки**
Документация по интеграции с продуктом **CARGO.RUN Загрузки** для грузоотправителей, экспедиторов и перевозчиков.

**Что внутри:**
- Создание и получение заказов через API
- Сценарии обмена с учетными системами (1С, ERP, TMS)
- Получение откликов перевозчиков и принятие выбранного отклика
- Отдельный сценарий интеграции перевозчика
- Справочник ключевых методов API

[Документация](./products/cargorun-loads/index.md)

---

### **CARGO.RUN Маршрутизация** (**YATRS**)
Документация по интеграции с продуктом **CARGO.RUN Маршрутизация** (**YATRS**), API для построения грузовых маршрутов и работы со справочниками дорожных ограничений.

**Что внутри:**
- Построение маршрута между двумя и более точками
- Авторизация по ApiKey и Bearer Token
- Справочники дорожных ограничений и типов ограничений
- Параметры маршрутизации, платные дороги и сезонные ограничения

[Документация](./products/cargorun-yatrs/yatrs.md)

---

### **CARGO.RUN Iris**
Документация по интеграции c продуктом **CARGO.RUN Iris**, асинхронный API для обмена данными между партнерскими логистическими сервисами и **CARGO.RUN Логистика**.

**Что внутри:**
- Авторизация и создание организаций в CARGO.RUN
- Описание API Iris
- Поддерживаемые модели и типы данных

[Документация](./products/cargorun-iris/index.md)
